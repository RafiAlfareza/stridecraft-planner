Cara Menghubungkan Latihan ke Smartwatch

Ada 2 cara praktis agar menu latihan, target pace, dan jarak muncul langsung di pergelangan tangan Anda saat berlari:

PENTING: Kenapa Garmin Web Menolak Upload File?

Halaman "Import Data" di web Garmin (connect.garmin.com/modern/import-data) hanya menerima riwayat aktivitas yang sudah selesai berlari, bukan rencana latihan (workout). Untuk memasukkan jadwal latihan ke Garmin, gunakan 3 cara resmi di bawah ini:

1 Cara 1: Sinkronisasi Kalender (.ics) — Otomatis Muncul di Jam Setiap Hari

Seluruh program latihan (8–16 minggu) langsung masuk ke widget Calendar di jam tangan Anda:

  1. Klik tombol hijau "Export Kalender (.ics)" di bagian atas web ini.
  2. Buka file tersebut di HP dan masukkan ke Google Calendar atau Apple Calendar.
  3. Buka aplikasi Garmin Connect di HP → Masuk ke tab More (•••) di kanan bawah → Settings → Connected Apps → Pilih Google Calendar / Calendar → Aktifkan Sync Workouts.
  4. Buka kalender di jam tangan Garmin Anda, menu latihan hari ini otomatis muncul di pergelangan tangan!
2 Cara 2: Kabel USB Langsung ke Jam (Format .FIT Asli Garmin) — 100% Berhasil

Jam Garmin membaca file biner .FIT seperti flashdisk:

  1. Buka "Detail Menu" pada sesi latihan yang diinginkan (misal Interval 5x800m).
  2. Klik tombol hijau "Garmin (.fit)" untuk mengunduh file biner asli Garmin.
  3. Hubungkan jam tangan Garmin ke laptop dengan kabel charger/data USB. Jam akan terbaca sebagai drive bernama GARMIN.
  4. Buka folder GARMIN/NewFiles (atau GARMIN/Workouts).
  5. Copy & paste file .fit yang baru diunduh ke dalam folder tersebut, lalu cabut kabel.
  6. Di jam Garmin Anda: Buka menu Lari (Run) → Tahan tombol tengah (Menu) → Pilih Training (Latihan) → Workouts. Latihan sudah siap dimulai dengan alarm getar interval!
3 Cara 3: Ekstensi Browser "Garmin Workout Importer" (Format .JSON)

Untuk memasukkan latihan langsung ke akun cloud Garmin Connect tanpa kabel:

  1. Pasang ekstensi gratis Chrome/Edge: Garmin Workout Importer dari Chrome Web Store.
  2. Di StrideCraft, buka Detail Menu lalu klik tombol biru "Garmin (.json)".
  3. Buka tab Garmin Connect Anda di browser, klik ikon ekstensi tersebut, lalu pilih file .json yang diunduh. Latihan langsung tersimpan di akun Garmin Anda dan otomatis tersinkron ke jam tangan!
